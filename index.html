AirNode

Wireless IoT Environmental Monitoring Network built using ESP32 microcontrollers and BME680 environmental sensors. Each node collects temperature, humidity, pressure, and gas resistance data, then transmits live readings over WiFi using MQTT to a custom web dashboard.
